# Fade — concept site (v2)

React + Vite + Tailwind. Zero animation libraries on purpose: one rAF-throttled
scroll pass in `App.jsx` writes `--p` (0→1) onto each `[data-scrub]` section,
and CSS does the rest — hero bend-back, dissolving layers, slide-over.

## Run

```powershell
cd oppo-scroll-demo-v2
npm install   # once
npm run dev   # open the printed localhost URL
```

Build: `npm run build` · Preview: `npm run preview`

## Content

All facts are real, from the `aiproj` repo: 16-dimension risk taxonomy, 50+
probe templates, ShopBot/DocBot/PayBot results, 50,000-run Monte Carlo premium
engine, hash-chained audit log.
